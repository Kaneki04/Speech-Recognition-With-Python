# Speech Recognition with Python

An early Python experiment for extracting audio from a video, transcribing speech, and translating the recognized text.

## What it uses

- Python
- MoviePy
- SpeechRecognition
- deep-translator
- Tkinter file picker

## Flow

1. Select a video file.
2. Extract its audio.
3. Enter source and target languages.
4. Transcribe the audio.
5. Translate the recognized text.

## Note

This is an older experimental project and may require dependency updates before running on a modern Python environment. It is kept as part of my Python learning history.
